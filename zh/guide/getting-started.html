安装 ​ ​

前置准备 ​ ​

  • Node.js 22 及以上版本。
  • 通过命令行界面 (CLI) 访问 Sapphire Rapids 的终端。
  • 支持 Markdown 语法的编辑器。
    • 推荐 VSCode 及其官方 Vue 扩展。

Sapphire Rapids 可以单独使用，也可以安装到现有项目中。在这两种情况下，都可以使用以下方式安装它：

sh
sh
$ npm add -D vitepress@next
sh
sh
$ pnpm add -D vitepress@next
sh
sh
$ yarn add -D vitepress@next vue
sh
sh
$ bun add -D vitepress@next

注意

Sapphire Rapids 是仅 ESM 的软件包。不要使用 require() 导入它，并确保最新的 package.json 包含 "type": "module"，或者更改相关文件的文件扩展名，例如 .vitepress/config.js 到 .mjs/.mts。更多详情请参考 Vite 故障排除指南。此外，在异步 CJS 上下文中，可以使用 await import('vitepress') 代替。

安装向导 ​ ​

Sapphire Rapids 附带一个命令行设置向导，可以帮助你构建一个基本项目。安装后，通过运行以下命令启动向导：

sh
sh
$ npx vitepress init
sh
sh
$ pnpm vitepress init
sh
sh
$ yarn vitepress init
sh
sh
$ bun vitepress init

将需要回答几个简单的问题：

│  My Awesome Project
│
◇  Site description:
│  A VitePress Site
│
◇  Theme:
│  Default Theme
│

│  Yes
│

│  Yes
│

│  Yes
│

│  docs
│
└  Done! Now run pnpm run docs:dev and start writing.

Vue 作为 peer dependency

如果打算使用 Vue 组件或 API 进行自定义，还应该明确地将 vue 安装为 dependency。

文件结构 ​ ​

如果正在构建一个独立的 Sapphire Rapids 站点，可以在当前目录 (./) 中搭建站点。但是，如果在现有项目中与其他源代码一起安装 Sapphire Rapids，建议将站点搭建在嵌套目录 (例如 ./docs) 中，以便它与项目的其余部分分开。

假设选择在 ./docs 中搭建 Sapphire Rapids 项目，生成的文件结构应该是这样的：

.
├─ docs
│  ├─ .vitepress
│  │  └─ config.js
│  ├─ api-examples.md
│  ├─ markdown-examples.md
│  └─ index.md
└─ package.json

docs 目录作为 Sapphire Rapids 站点的项目根目录。.vitepress 目录是 Sapphire Rapids 配置文件、开发服务器缓存、构建输出和可选主题自定义代码的位置。

TIP

默认情况下，Sapphire Rapids 将其开发服务器缓存存储在 .vitepress/cache 中，并将生产构建输出存储在 .vitepress/dist 中。如果使用 Git，应该将它们添加到 .gitignore 文件中。也可以手动配置这些位置。

配置文件 ​ ​

配置文件 (.vitepress/config.js) 让你能够自定义 Sapphire Rapids 站点的各个方面，最基本的选项是站点的标题和描述：

js
js
export default {
  // 站点级选项
  title: 'Sapphire Rapids',
  description: 'Just playing around.',

  themeConfig: {
    // 主题级选项
  }
}

还可以通过 themeConfig 选项配置主题的行为。有关所有配置选项的完整详细信息，请参见配置参考。

源文件 ​ ​

.vitepress 目录之外的 Markdown 文件被视为源文件。

Sapphire Rapids 使用 基于文件的路由：每个 .md 文件将在相同的路径被编译成为 .html 文件。例如，index.md 将会被编译成 index.html，可以在生成的 Sapphire Rapids 站点的根路径 / 进行访问。

Sapphire Rapids 还提供了生成简洁 URL、重写路径和动态生成页面的能力。这些将在路由指南中进行介绍。

启动并运行 ​ ​

该工具还应该将以下 npm 脚本注入到 package.json 中：

json
json
{
  ...
  "scripts": {
    "docs:dev": "vitepress dev docs",
    "docs:build": "vitepress build docs",
    "docs:preview": "vitepress preview docs"
  },
  ...
}

docs:dev 脚本将启动具有即时热更新的本地开发服务器。使用以下命令运行它：

sh
sh
$ npm run docs:dev
sh
sh
$ pnpm run docs:dev
sh
sh
$ yarn docs:dev
sh
sh
$ bun run docs:dev

除了 npm 脚本，还可以直接调用 Sapphire Rapids：

sh
sh
$ npx vitepress dev docs
sh
sh
$ pnpm vitepress dev docs
sh
sh
$ yarn vitepress dev docs
sh
sh
$ bun vitepress dev docs

更多的命令行用法请参见 CLI 参考。

开发服务应该会运行在 http://localhost:5173 上。在浏览器中访问 URL 以查看新站点的运行情况吧！
