Что такое Sapphire Rapids?
Первые шаги
GitHub

  • Сосредоточьтесь на своем контенте

    Легко создавайте красивые сайты с документацией, используя только Markdown.

  • Наслаждайтесь опытом разработчиков Vite

    Мгновенный запуск сервера, молниеносные горячие обновления и использование плагинов экосистемы Vite.

  • Настройка с помощью Vue

    Используйте синтаксис Vue и компоненты прямо в Markdown или создавайте собственные темы с помощью Vue.

  • Быстрый запуск веб-сайтов

    Быстрая начальная загрузка с помощью статического HTML, быстрая навигация после загрузки с помощью маршрутизации на стороне клиента.
