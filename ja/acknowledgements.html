謝辞 ​ ​

当サイト ヴワル魔法図書館 の構築においては、現代のオープンソースソフトウェア領域における数多くの先進的な技術を結集・活用させていただきました。高速な静的ビルドシステム、洗練されたタイポグラフィとインタラクション、そして充実した閲覧体験向上プラグインなど、これらはすべてオープンソースコミュニティの惜しみない貢献によるものです。

ここに、以下の素晴らしいオープンソースプロジェクト、その開発チーム、および世界中のすべてのコントリビューターに心からの敬意と感謝の意を表します。

🌟 コア基盤プロジェクト ​ ​

1. VitePress ​ ​

  • チーム・創作者：Evan You（尤雨溪）および VitePress コントリビューターチーム
  • 公式サイト：vitepress.dev
  • オープンソースリポジトリ：vuejs/vitepress
  • ライセンス：MIT License
  • 謝辞と役割：本サイトのドキュメントシステムアーキテクチャ、インタラクション設計、コアスタイルは VitePress 公式ドキュメントに由来しています。

2. Vue.js ​ ​

  • チーム・創作者：Evan You および Vue.js コアチーム
  • 公式サイト：vuejs.org
  • オープンソースリポジトリ：vuejs/core
  • ライセンス：MIT License
  • 謝辞と役割：サイト全体の基盤フレームワークとして、Vue 3 の Composition API とリアクティブシステムが柔軟な拡張性を実現しています。

3. Vite ​ ​

  • チーム・創作者：Evan You および Vite チーム
  • 公式サイト：vite.dev
  • オープンソースリポジトリ：vitejs/vite
  • ライセンス：MIT License
  • 謝辞と役割：ミリ秒レベルの高速ホットリロード（HMR）と高効率な本番ビルドを提供する次世代フロントエンドツールです。

🧩 ナレッジベースエコシステム＆拡張プラグイン ​ ​

4. Nólëbase ​ ​

  • 創作者：絢香猫 (@nekomeowww)、絢香音 (@LittleSound) およびコミュニティ
  • 公式サイト：nolebase.ayaka.io
  • オープンソースリポジトリ：nolebase/nolebase / nolebase/integrations
  • ライセンス：MIT License
  • 謝辞と役割：本プロジェクトのベーステンプレートアーキテクチャ。閲覧体験強化（Enhanced Readabilities）、アウトラインスポットライト、インラインプレビュー、Git 更新履歴解析などのプラグインを提供しています。

5. UnoCSS ​ ​

  • チーム・創作者：Anthony Fu およびコミュニティ
  • 公式サイト：unocss.dev
  • オープンソースリポジトリ：unocss/unocss
  • ライセンス：MIT License
  • 謝辞と役割：高速かつ高性能なアトミック CSS エンジン。

6. VueUse ​ ​

  • チーム・創作者：Anthony Fu および VueUse コントリビューター
  • 公式サイト：vueuse.org
  • オープンソースリポジトリ：vueuse/vueuse
  • ライセンス：MIT License
  • 謝辞と役割：クリップボードコピーや状態監視など、便利な Composition API ユーティリティ集。

7. Markdown-it エコシステム ​ ​

  • 主要モジュール：markdown-it, markdown-it-footnote 等
  • ライセンス：MIT License
  • 謝辞と役割：柔軟で拡張性の高い Markdown 構文解析・レンダリング基盤を提供しています。
