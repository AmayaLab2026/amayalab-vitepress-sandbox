謝辞
GitHub

  • 厳密な化学構造図

    アレクサンダー・シュルギン博士による全33枚の母核骨格図を収録。アヘン環の簡略化、フェンタニル誘導体、幻覚分子のトポロジーを明解に図解。

  • 法律と科学の交差点

    米国連邦規制物質法（CSA）の5段階スケジュール分類論理、緊急指定権限、類似体法の判定課題を多角的に解説。

  • 領域横断の権威典籍

    法学、法中毒学、創薬化学の三界の権威による序文を結集。法曹関係者と研究化学者の垣根を取り払う必読書。

  • 洗練された読書体験

    VitePress と Claude 風の温かみある紙面デザイン仕様に基づき、カプセル型UIと優雅なセリフ組版で上質な読書体験を提供。
